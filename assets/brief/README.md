# Brief illustrations

One image per issue of the Al Liwan AI Brief, named by the issue date. Email
cannot carry a local file and Gmail strips data URIs, so each issue's
illustration has to sit at a public https URL before that issue can be sent.

These are static assets. Nothing on the site links to them.

Generated to the brief's visual system: the Al Liwan Labs palette and nothing
outside it, flat geometric architecture built on the Labs arch, no human
figures, no glow or gradients, no text baked into the image. The system and the
prompt template live with the brief, not here.
